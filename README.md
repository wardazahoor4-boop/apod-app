MY SPACE PICTUE VIEWER


This is a fun little project I built for Hack Club that shows awesome space photos from NASA!

What it can do:



. Shows daily space photos straight from NASA

. Has a calendar box so you can pick any date you want

. Has a random button for fun surprises

. Includes a clock you can hide or show

. Pulls photos and info using the NASA API


Why I made this:




I wanted to practice my coding skills and make something cool about space that updates every day.



Things I used:



. HTML

. CSS

. JavaScript

. NASA's photo API
